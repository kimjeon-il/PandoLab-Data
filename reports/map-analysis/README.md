# 지도 분석 파일 분류

[전체 보고서 구조 정책](../POLICY.md)의 지도 분석 조항에 따릅니다. 기존 이미지·지도 원본의 재배포 조건과 출처 표기를 유지합니다.

| 구분 | 경로 | 저장 내용 |
| --- | --- | --- |
| 원본 자료 | `corpus/{dataset}/sources/`, `corpus/sources/` | 기관 제공 원본 지도·이미지·ZIP·PDF 및 출처·저작권 메타데이터 |
| 학습 원장 | `corpus/{dataset}/corpus*.training.json`, `labels/` | 학습 표본 목록·원도면/라벨 상대경로·데이터 분할 정보 |
| 학습 중간 입력 | `corpus/{dataset}/derived/` | 학습 명세가 참조하는 변환 이미지·마스크·타일 |
| 모델·평가 | `models/` | 모델 가중치, 훈련 메타데이터 및 평가·진단 스냅샷 |
| 분석 결과 | `results/` | 실행 결과·진단 로그·내보내기 파일·플러그인 전환 검증 |

완료된 결과의 정본을 `results/` 밖으로 새로 복제하지 않습니다. `corpus/gazetteer-v1/runtime/`의 4,353개 분할 인덱스는 현재 참조 보존을 위해 경로를 유지하며, 원자료가 아니라 검색용 파생 데이터라는 의미입니다. 원본과 학습 자료가 혼재된 기존 코퍼스의 상대경로를 바꾸는 작업은 해당 소비자의 참조·해시 검증과 함께 별도로 해야 합니다. 보고서 정리만으로 별도 빌드·GIS 재생성을 실행하지 않습니다.
