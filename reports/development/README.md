# 개발 검증·성능·릴리스 증거

완료된 개발 검증은 **주제별 구조화 JSON**을 우선 정본으로 둡니다. `performance/`·`rendering/`은 현재 Viewer의 지도 품질 및 LOD 관찰 결과, `storage/`는 저장·캐시 검증, `ui/`는 화면 계약 및 현재 UI 증거, `integrations/`·`releases/`는 이전 릴리스의 이력, `native/`는 네이티브 결합 조사입니다.

완료된 릴리스의 임시 `.log`, `.gz`, 임베디드 일회성 실행 코드, 중복 이미지 등은 제거했습니다. 삭제된 경로·Git blob SHA·사유는 `RETIRED-EVIDENCE-INDEX.json`에 기록해 내용 복사 없이 이전 Git 기록에서 조회할 수 있게 했습니다. 형상·원본 GIS와 현재 실행 코드는 `reports/` 밖의 전용 자산/도구에서 관리합니다.

현재 개발 상태를 판단할 때는 오래된 통과 로그가 아니라 해당 시점의 실제 실행 원장과 최종 검증 결과를 확인해야 합니다. 전체 빌드나 테스트 재실행은 이 정리의 일부가 아닙니다.
