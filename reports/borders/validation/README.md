# 국경 검증 자료

최종 국경·영토 자료는 `../data/`와 `../reconstruction/`, 역사 증거는 `../history/`를 기준으로 구분합니다.

이곳의 날짜별 폴더에는 검증 당시의 JSON 판정, 지리 원본 및 비교 자료를 보존합니다. **완료된 일회성 `.mjs`와 반복 콘솔 `.log`를 현행 실행 코드로 취급하지 않습니다.** 삭제된 파일의 상대경로와 Git blob SHA는 `RETIRED-ONE-OFF-INDEX.json`에 남겼습니다. 복구가 필요한 경우 해당 Git 커밋에서 확인할 수 있습니다.

`modern-raw-source-20261110/*/evidence-rollup*.json`은 국가별로 쪼개졌던 일회성 평가 JSON의 내용을 그룹별로 합친 정본입니다. 도형 원본 `.geojson`, `.gpkg`와 대형 형상 데이터는 변환하지 않았습니다.
